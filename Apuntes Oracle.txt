Oracle maneja una sola base de datos por servidor. (se podria tener mas, pero no es recomendable). Para manejar distintos proyectos, Oracle maneja esquemas.
	select * from V$Database
Esquema y usuario, para oracle es lo mismo.
	select * from dba_users
	
	
--------------------------------------------------------------------
Listar todos los usuarios/esquemas de la BD
	select * from dba_users
	
Cambiar la fecha de expiración de la contraseña
	ALTER PROFILE DEFAULT LIMIT PASSWORD_LIFE_TIME 90 -- Contraseña Caduca cada 90 días
	ALTER PROFILE DEFAULT LIMIT PASSWORD_LIFE_TIME UNLIMITED -- Contraseña no caduca

Cambiar la contraseña de un usuario/esquemas
	ALTER USER SYSTEM IDENTIFIED BY 123_NuevaContraseña

Al cambiar la clave el usuario no puede reutilizar su clave por 90 días
	ALTER PROFILE DEFAULT LIMIT PASSWORD_REUSE_TIME 90 PASSWORD_REUSE_MAX UNLIMITED;
	

Desbloquear al usuario
	ALTER USER SYSTEM ACCOUNT UNLOCK -- NO funciona para aquellas que se han bloqueado por su fecha de expiración de la contraseña
